# Guardian Cloud — Beta Feedback

## Objetivo

Este documento recoge feedback real de la beta cerrada de Guardian Cloud.

La prioridad NO es añadir funciones nuevas.

La prioridad es validar:

- supervivencia de evidencia
- claridad de uso
- confianza percibida
- estabilidad real
- recovery automático
- comportamiento en condiciones malas

---

# Reglas de la beta

## IMPORTANTE

Guardian Cloud NO se evalúa como una app “bonita”.

Se evalúa como:
- herramienta de protección
- sistema resiliente
- aplicación simple y confiable

---

# Qué observar especialmente

## UX
- ¿La persona entiende qué hace la app?
- ¿Entiende “Protegido”?
- ¿Entiende exportar?
- ¿Confía en la aplicación?

## Recovery
- ¿La app recupera sola?
- ¿Necesita reiniciar?
- ¿El usuario entiende lo que ocurre?

## Estabilidad
- ¿Hay cuelgues?
- ¿Hay loops?
- ¿Hay uploads infinitos?
- ¿Se pierde evidencia?

## Claridad
- ¿El usuario duda demasiado?
- ¿Pregunta “qué tengo que hacer”?
- ¿La app genera ansiedad o confianza?

---

# Severidad

| Nivel | Significado |
|---|---|
| CRÍTICO | Posible pérdida de evidencia |
| ALTO | Recovery roto o bloqueo grave |
| MEDIO | Función importante confusa o inestable |
| BAJO | Problema menor visual o UX |
| INFO | Observación o sugerencia |
